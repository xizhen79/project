policy

가져오기 오류 및 예외 처리 정책 가이드

형식 불일치나 무결성 훼손 파일 유입 시 안전 장치가 가동되어 대시보드가 오염되지 않습니다.

안전 보호 모드 가동
1. 필수 열 누락 발생 시 오류 차단

15개 필수 컬럼 중 하나라도 헤더에 존재하지 않는 경우 파싱을 즉시 중단하고 누락된 열 명칭(예: 누적기성액)을 모달로 표출합니다.

조치: 기본 템플릿 양식 다운로드 후 열 재구성 필요
2. 날짜/타입 형식 오류 시 행 단위 적발

년월이 YYYY-MM 규격이 아니거나 공정률에 문자가 기입된 경우, 오류 발생 행 번호(Row #)와 해당 원문 값을 리포트합니다.

조치: 셀 서식 텍스트/숫자 분리 후 재저장
3. 누적액/공정률 역전 시 논리 검증 경고

당월 누적기성액이 전월 누적기성액보다 감소하여 당월기성액이 음수가 발생하거나, 공정률이 역주행할 경우 정밀 소명 사유가 없으면 저장을 보류합니다.

조치: 기성 감액 정산 합의서 첨부 여부 확인
lock 기존 데이터 안전 보존 원칙: 파일 검증 중 단 1개의 행이라도 치명적 오류가 발견되면 파일 가져오기 작업이 자동 취소되며, 현재 운영 중인 기존 144행 데이터는 단 1건의 손실 없이 원형대로 유지됩니다.
