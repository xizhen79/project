# 현장별 공정·기성 대시보드 — FRD(기능 요구사항 문서)

## 한눈에 보기

- 월·지역·유형·현장을 바꾸면 숫자·추이·비교표·CSV·AI에 같은 범위를 적용합니다.
- 점검 순위의 현장을 누르면 비교표의 해당 행을 강조하고 상황·대응 기록을 펼칩니다.
- 누적기성액은 월말까지의 금액, 당월기성액은 바로 전월 누적액과의 차액이며 첫 달은 계산 불가입니다.
- 가져오기는 검사·미리보기 후 전체 교체하며, 오류·취소 시 기존 자료를 유지합니다.
- AI는 계산값과 원문 기록을 설명하고, 필터 변경 시 이전 답변을 지우며 연결 실패 시에도 조회·CSV는 유지합니다.

## 기능별 표

|---|---|---|---|---|---|

| F02 | 첫 실행·새로고침 | 앱을 열거나 새로고침 | 저장 자료를 자동 복구하지 않음 | 자료 없음과 파일을 다시 가져오라는 안내. 지표는 계산 불가 | 자료가 없으면 CSV·AI 전송을 사용할 수 없게 표시. 가짜 0%·완료 상태를 보여주지 않음 |
| F03 | 월 선택 | 기준 월을 고름 | 현재 지표·표·순위는 선택 월로 계산. 추이는 시작 월~선택 월로 계산 | 기준 월 표시와 해당 월 결과. 정상 원본 적용 시 기본값 2026년 9월 | 해당 월 자료가 없으면 자료 없음·계산 불가. 다른 월 자료를 대신 표시하지 않음 |
| F04 | 지역 선택 | 전체 지역 또는 지역 하나를 고름 | 검사한 자료의 지역으로 선택지 구성. 지역·기존 유형의 교집합 적용. 선택 현장이 범위 밖이면 현장을 전체로 변경 | 같은 지역 범위의 모든 숫자·차트·표·CSV·AI | 현장 선택이 해제되면 전체 현장으로 바뀌었음을 안내. 결과가 없으면 자료 없음 |
| F05 | 공사 유형 선택 | 전체 공사 유형 또는 유형 하나를 고름 | 검사한 자료의 유형으로 선택지 구성. 유형·기존 지역의 교집합 적용. 선택 현장이 범위 밖이면 현장을 전체로 변경 | 같은 유형 범위의 모든 결과 | 조건에 맞는 현장이 없으면 자료 없음. 임의로 지역 조건을 풀지 않음 |
| F06 | 현장 선택 | 전체 현장 또는 현장 하나를 고름 | 현재 지역·유형에 속하는 현장 중 선택. 해당 범위로 지표와 월별 추이를 계산 | 9월 D 선택 시 기성률 69.4%, 비교표 1행 | 월별 행이 없으면 해당 월은 자료 없음·계산 불가. 다른 현장 값으로 채우지 않음 |
| F07 | 필터 반영·초기화 | 필터를 변경하거나 필터 초기화를 누름 | **(AI 결정)** 별도 적용 버튼 없이 즉시 반영. 초기화는 지역·유형·현장을 전체, 월을 기본 조회 월로 변경. 필터 변경 시 이전 AI 답변 제거 | 페이지 어디에서 바꿔도 같은 범위. 현재 범위를 월·지역·유형·현장으로 표시 | 필터 변경 시 이전 비교표 강조·펼침을 해제 **(AI 결정)**. 이전 범위의 기록이 새 결과에 남지 않음 |
| F08 | 전체 현황 숫자 | 현황 요약을 엶 | 선택 월·범위의 기성률·계획/실제 공정률·공정차이 계산 | 큰 숫자 4개. 보조 금액에 계약금액·누적기성액·당월기성액을 각각 구분해 표시 | 분모나 자료가 없으면 계산 불가. 전체 평균 상태를 개별 현장의 상태로 대신 쓰지 않음 |
| F09 | 계획·실제 월별 추이 | 현황 요약에서 차트를 보거나 월별 점에 마우스를 올림 | 같은 지역·유형·현장 조건으로 월마다 계약금액 비중을 반영해 별도 집계 | 선택 월까지 계획선·실제선, 월·계획/실제 공정률·공정차이 안내. 9월 전체는 12개월 | 빠진 월은 연결해 추정하거나 0으로 채우지 않고 계산 불가로 구분 |
| F10 | 월별 당월기성 막대 | 차트의 월별 막대에 마우스를 올림 | 같은 범위의 각 현장에 바로 전월 자료가 있는지 확인하고 차액 합산 | 비율 축은 %, 금액 축은 백만원. 9월 전체 막대 28,878.7. 안내에는 당월기성액과 누적기성액을 별도 이름으로 표시 | 첫 달·전월 누락은 막대값 없음과 계산 불가로 표시. J의 7월 0.0은 정상값으로 표시. 전체 막대를 J 하나의 0.0으로 바꾸지 않음 |

### 점검 현장과 비교표

| 번호 | 기능 | 사용자가 하는 일 | 프로그램이 하는 일 | 화면에 보이는 결과 | 오류·예외일 때 |
|---|---|---|---|---|---|
| F11 | 점검 순위·상태 수 | 현황 요약의 점검 목록을 봄 | 선택 월·범위에서 공정차이 −5pp 이하만 순위화. 차이가 작은 순, 같으면 현장 ID 순. 정상·주의·점검 수를 각각 계산 | 9월 전체 D(−10.7pp) → I(−7.6pp) → K(−5.4pp). 각 행에 계획·실제 공정률·기성률과 공정차이 표시. 정상 6·주의 3·점검 3곳 | 유효 자료는 있으나 점검 현장이 없으면 점검 대상 없음. 자료 자체가 없는 경우와 구별 |
| F12 | 점검 행에서 비교표로 이동 | 점검 현장 행을 누름 | 월·지역·유형·현장 필터를 유지한 채 비교표로 이동. 해당 현장 행까지 이동하고 강조·기록 펼침 | D를 누르면 D 행의 ID·현장명과 기록이 보임. 다른 현장 행도 기존 범위대로 유지 | 대상 행이 새 자료·필터에서 사라지면 다른 행을 대신 열지 않음. 현재 범위에 자료가 없다고 안내 |
| F13 | 현장별 비교표 조회 | 현장별 비교표를 엶 | 선택 월·범위의 현장당 한 행 표시. **(AI 결정)** 표도 공정차이가 작은 순, 동점은 현장 ID 순으로 고정 | 현장 ID·가상 현장명·지역·유형·당월 주요 공종·계약금액·누적기성액·기성률·계획/실제 공정률·공정차이·당월기성액·상태·기록 펼침. 9월 전체 12행 | 표본 시안의 6개 행을 전체 12개로 간주하지 않음. 넓은 표는 가로로 이동해 열을 확인 **(AI 결정)** |
| F14 | 상황·대응 기록 펼침/접기 | 행 또는 기록 펼침을 누르고, 다시 누르면 접음 | 선택 월·현장의 원문 필드를 같은 페이지의 아래 행에 표시. 버튼을 눌렀을 때 중복으로 열고 닫히지 않게 처리 | 착공일~계약상 준공일, 당월 주요 공종, 특이사항 분류, 기록된 상황, 기록된 대응 계획. 버튼 문구는 펼침/접기로 변경 | 계약상 준공일은 실제 완료일로 표현하지 않음. 기록을 요약해 원인 확정·대응 완료로 바꾸지 않음 |
| F15 | 여러 기록 비교·전체 접기 | 여러 행을 펼치거나 전체 접기를 누름 | **(AI 결정)** 여러 행을 동시에 펼칠 수 있음. 전체 접기는 열린 기록만 모두 접음 | 시안의 행 안 기록 패널을 유지. 처음 비교표를 직접 열면 모두 접힘, 점검 순위로 오면 해당 행은 펼침 **(AI 결정)** | 접어도 원본 자료·필터·숫자는 유지. 필터 변경·자료 교체 시 이전 행의 펼침 상태 해제 |

### 자료 가져오기와 CSV

| 번호 | 기능 | 사용자가 하는 일 | 프로그램이 하는 일 | 화면에 보이는 결과 | 오류·예외일 때 |
|---|---|---|---|---|---|
| F16 | 파일 선택 | 파일 선택을 누르거나 CSV/JSON 하나를 끌어다 놓음 | 브라우저에서 파일을 읽고 아직 적용하지 않은 검사 대상으로 보관 | 파일명·형식·행 수, 검사 진행 표시 | 선택창 취소는 기존 자료 유지. 읽기 실패·지원하지 않는 형식은 이유 안내 후 반영하지 않음 |
| F17 | 파일 검사 | 파일 선택 후 검사 결과를 봄 | 아래 입력 검사 기준을 전체 행에 적용. 원본의 15개 열과 JSON 단위 정보를 확인 | 성공·오류·경고 수, 오류 행·열·값·이유. 전월 없음은 당월기성 계산 불가 안내 | 오류가 하나라도 있으면 전체 교체 버튼 사용 불가. 일부 정상 행만 몰래 적용하지 않음 |
| F18 | 미리보기 | 검사 결과와 표를 확인 | 원본 필드와 계산된 미리보기 값을 구별. **(AI 결정)** 파일 순서의 앞 5행을 표시하고 전체 행 수를 함께 표시 | 정상 원본은 144행·15개 원본 열. 계산 결과는 별도 표시. CSV는 설명서의 백만원·% 단위를 사용한다고 안내 | 월별 누락은 경고와 실제 집계 대상 안내. 첫 달 계산 불가를 오류로 취급하지 않음 |
| F19 | 가져오기 취소 | 취소하고 기존 자료 유지를 누름 | 검사 중인 새 파일과 미리보기만 폐기. **(AI 결정)** 적용 전 다른 페이지로 나가도 새 파일을 반영하지 않음 | 기존 자료·필터·숫자 유지. 이전 자료가 없으면 자료 없음 | 검사 중 기존 자료의 일부를 미리 덮어쓰지 않음 |
| F20 | 전체 교체 적용 | 검사 완료 후 데이터 전체 교체 적용하기를 누름 | 검사한 자료 전부를 한 번에 교체. 새 자료 기준으로 계산. 이전 AI 답변·진행 요청·강조·펼침 제거 | 적용 완료와 실제 행 수. 정상 CSV 다음 JSON도 144행. **(AI 결정)** 지역·유형·현장은 전체, 월은 2026년 9월이 있으면 9월, 없으면 파일의 마지막 월 | 교체 중 실패하면 기존 자료·필터 유지. 검사 후 다른 파일을 선택했다면 이전 파일의 완료 결과로 적용하지 않음 |
| F21 | 선택 범위 CSV 내보내기 | CSV 내보내기를 누름 | 현재 적용 자료의 선택 월·지역·유형·현장 행만 추출. 원본 15개 열 순서 뒤에 기성률(%)·공정차이(pp)·상태·당월기성액(백만원) 추가. UTF-8 BOM(엑셀이 한글 파일임을 식별하도록 돕는 저장 방식) 사용 | 파일 다운로드. D는 데이터 1행, 9월 인천·공동주택은 A·G 2행. 금액은 백만원, 비율은 % 수치 유지 | 자료 없음은 다운로드 불가 안내 **(AI 결정)**. 실패 시 자료 유지와 다시 시도 안내. 첫 달 당월기성액은 계산 불가로 내보내고 0으로 바꾸지 않음 |

### AI에게 묻기

| 번호 | 기능 | 사용자가 하는 일 | 프로그램이 하는 일 | 화면에 보이는 결과 | 오류·예외일 때 |
|---|---|---|---|---|---|
| F22 | 예시 질문·질문 입력 | 예시 질문을 누르거나 직접 입력 | **(AI 결정)** 예시를 입력칸에 채우고 전송을 기다림. PRD의 예시 질문을 사용 | “D 현장은 왜 점검 대상이고, 기록된 대응 계획은 무엇인가요?”와 현재 월·지역·유형·현장 | D가 현재 범위 밖이면 자동으로 필터를 바꾸지 않음. 전송 시 현재 자료 범위의 한계를 설명 |
| F23 | 질문 전송·대기 | 전송을 누르거나 Enter로 전송 | 빈 질문·자료 유무 확인. Gemini API(외부 AI 기능을 요청하는 방법)는 서버에서만 호출. 프로그램 계산값과 원문 기록을 구분해 전달 | 질문, AI 답변 기다리는 중. **(AI 결정)** 같은 요청 대기 중 중복 전송 방지 | 빈 질문은 입력 안내, 자료 없음은 가져오기 안내. 대기 중에도 필터·페이지 이동·CSV 사용 가능 |
| F24 | 근거 있는 답변 | 답변의 숫자·기록을 확인 | 선택 월 원문 행과 계산값을 전달. 추이는 같은 필터의 시작 월~선택 월 요약도 전달. **(AI 결정)** 한 현장 선택 시 해당 기간의 월별 기록도 함께 전달 | 답변에 기준 월·현장 ID, 계산 근거, 기록된 상황(issueSummary), 대응 계획(actionPlan)을 구분. D의 공급 정상화 후 잔여 지연·주간 확인 계획을 원문대로 설명 | 과거 월 원문을 전달하지 않았다면 해당 월의 이유를 만들지 않음. 전달된 범위 밖 사실은 자료 없음 안내 |
| F25 | 답변 범위 보호·초기화 | 필터를 바꾸거나 대화 초기화를 누름 | 필터 변경·새 자료 적용 시 이전 답변 제거. 요청 당시 자료·필터와 현재 값이 다른 늦은 응답은 표시하지 않음. 초기화는 질문·답변만 제거 **(AI 결정)** | 새 범위 표시와 빈 답변 영역. 초기화해도 자료·필터·차트 유지 | 요청을 중단하지 못해도 이전 범위 응답은 버림. 이전 범위의 답변을 현재 답변으로 표시하지 않음 |
| F26 | 자료에 없는 질문 처리 | 실제 준공일·미수금·미래 일정 등을 질문 | 계약상 준공일과 실제 완료일을 구별하도록 전달. 수금·미수금·기상 실측·완료 여부를 추정하지 않음 | 자료가 없어 알 수 없다는 설명. 기록된 대응은 계획으로 표시 | 가상의 계약상 날짜를 실제 준공 보장일·예측일로 바꾸지 않음 |
| F27 | AI 실패 처리 | 실패 안내를 확인하고 다시 전송 | 키 없음·한도 초과·통신/시간 초과·응답 오류를 사용자가 이해할 문구로 구분. 현재 필터 기준으로 재전송 | AI 연결 실패, 다시 시도 안내, 대시보드·CSV는 계속 쓸 수 있다는 안내 | 키 값·내부 오류 내용은 노출하지 않음. **(AI 결정)** 실패한 질문 입력은 남겨 다시 전송 가능. 모의 응답은 실제 성공으로 표시하지 않음 |

### 입력 검사 기준

|---|---|---|---|

| 파일 구조 | CSV는 표의 열과 행을 읽을 수 있어야 함. JSON은 metadata(단위·버전 등의 자료 설명)와 records(자료 행 목록)의 구조를 확인 | 해석할 수 없는 파일·잘못된 구조는 전체 거부. 원본 행은 고치지 않음 | 검사되지 않은 값의 반영 방지 |
| JSON 단위·버전 | schemaVersion=2.0, moneyUnit=백만원, progressUnit=percent_0_100, requiredFields가 원본 15개 필드를 나타냄 | 기준과 다른 단위·버전·필드 정보는 오류. 임의 단위 변환 금지 | 데이터설명: 단위·자료 형식 혼동 방지 |
| 월·현장 ID | month는 2025-10~2026-09의 YYYY-MM, siteId는 A~L. 같은 month+siteId는 한 행 | 날짜 형식·범위 오류·중복이면 전체 거부 | 한 현장의 한 월말 상태를 한 번만 계산 |
| 현장 고정 정보 | 같은 siteId의 가상 현장명·지역·유형·계약금액·착공일·계약상 준공일은 모든 월에서 동일. 명칭은 [가상] 표시, 지역·유형은 설명서 목록 사용 | 다른 현장 정보가 섞이면 오류 위치 안내 후 전체 거부 | 서로 다른 계약·현장을 같은 현장으로 계산하지 않도록 함 |
| 숫자 | 계약금액 >0, 계획/실제 공정률은 0~100, 누적기성액은 0~계약금액. 모두 유효한 유한 숫자 | 문자·빈값·무한값·범위 밖 값은 오류. 숫자 0 자체를 누락으로 판단하지 않음 | 잘못된 분모·공정률·기성액 방지 |
| 날짜 | YYYY-MM-DD의 실제 날짜. 착공일 < 계약상 준공일, 기록 월말은 착공일 이후 또는 같은 날 | 잘못된 날짜·순서면 오류 | 공사기간과 기록 월의 일관성 확보 |
| 누적값 | 현장별로 월을 정렬해 계획/실제 공정률·누적기성액이 감소하지 않는지 검사 | 감소는 이번 교육 자료에서 오류. 소명서 첨부 등으로 통과시키지 않음 | 데이터설명: 실무 정정·설계 변경은 이번 범위 밖 |
| 월별 누락·일부 파일 | 정상 원본은 144행. 일부 월·현장만 있는 CSV도 검사 가능 | 누락은 경고하고 확인 가능한 행·현장 수만 집계했다고 표시. 바로 전월이 없으면 당월기성액 계산 불가 | 선택 범위 내보내기와 첫 달의 정상적인 계산 불가를 허용 |
| 내보낸 CSV의 계산 열 | **(AI 결정)** 원본 15개 열을 계산 기준으로 읽고 추가 계산 열은 무시하여 재계산 | 기성률·공정차이·상태·당월기성액을 원본의 확정값으로 신뢰하지 않음 | 원본에 계산값을 중복 저장하지 않는 규칙 유지 |
