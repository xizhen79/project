# 현장별 공정·기성 대시보드 — PRD

## 한눈에 보기

- 본사 공무팀 담당자가 매달 사용하는 PC용 현장 공정·기성 대시보드입니다.
- 늦어진 현장을 늦게 알아채는 불편을 줄입니다.
- 전체 숫자 → 점검 순위 → 현장 기록과 월별 변화 순으로 확인합니다.
- 자료 가져오기·현황·점검·CSV·AI 설명을 모두 포함합니다.
- 교육용 가상 자료만 사용하며, 계산과 기록을 근거로 판단합니다.

## 기준 문서와 자료

| 항목 | 기준 | 이유 |
|---|---|---|
| 작업·범위 | `작업규칙.md`, `실습조건.md` | 기능과 작업 순서를 일관되게 유지 |
| 자료·단위·계산 | `data/데이터설명.md`, `data/검산표.md` | 정해진 산식과 예상값으로 검증 |
| 원본 | `data/현장공정기성.csv`, `data/현장공정기성.json` | 두 형식은 같은 144행·15개 열 |
| 자료 범위 | 가상 현장 A~L 12곳, 2025년 10월~2026년 9월 12개월 | 한 행은 한 현장의 한 달 월말 상태 |
| 사용 경계 | 교육용 합성 자료이며 실제 동일토건의 계약·현장·실적·기상·사업 구성을 나타내지 않음 | 가상 기록을 실제 회사의 사실로 오해하지 않도록 함 |

원본 자료는 수정하지 않습니다. 이 문서의 성공 기준은 앞으로 만들 앱의 기대 결과이며, 앱 테스트를 이미 통과했다는 뜻이 아닙니다.

## 누가·언제·왜 쓰는지

| 항목 | 정한 내용 | 이유 |
|---|---|---|
| 사용자 | 본사 공무팀 담당자 | 여러 현장의 자료를 모아 보고하는 역할 |
| 사용 시점 | 매달 현장 자료를 취합해 현황을 점검할 때 | 자료 한 행이 한 현장의 월말 상태 |
| 사용 목적 | 늦어진 현장을 찾고, 변화와 기록된 대응을 확인 | 전체 평균만 보면 개별 현장의 지연을 놓칠 수 있음 |
| 핵심 흐름 | 자료 가져오기 → 점검 현장 확인 → 기록·추이 확인 → CSV 또는 AI 설명 활용 | 발견한 지연의 숫자와 기록을 이어서 확인 |

## 줄이고 싶은 불편

가장 먼저 줄일 불편은 **늦어진 현장을 늦게 알아채는 것**입니다. 전체 숫자와 함께 점검 순위를 보여주고, 해당 현장의 상황·대응 계획과 월별 변화를 바로 확인하도록 만듭니다.

| 자료에서 확인한 사례 | 제품에 반영할 내용 | 이유 |
|---|---|---|
| 9월 점검 현장은 D·I·K | 공정차이가 작은 순으로 점검 현장 표시 | 지연이 큰 현장부터 확인 |
| D는 8월 −11.2pp에서 9월 −10.7pp로 차이가 줄었지만 점검 유지 | 현재 상태와 월별 추이를 함께 표시 | 개선과 정상 회복을 구별 |
| B는 납기 지연 후 정상 범위로 회복, F는 우천 시나리오 이후 일부 회복 | 현장별 숫자와 원문 기록을 연결 | 현장마다 경과와 대응이 다름 |
| J는 7월 기성 확인 서류 보완으로 당월기성액 0.0, 시공은 계속 진행 | 기성 막대와 원문 기록을 함께 확인 | 기성액 정체를 공사 중단으로 오해하지 않도록 함 |
| 7개 지역·5개 공사 유형이 포함됨 | 지역·유형·현장 필터 제공 | 필요한 범위만 비교 |

## 만들 기능

아래 다섯 기능은 모두 필수이며 로컬 구현과 검증까지 진행합니다.

| 필수 기능 | 요구사항 | 이유 |
|---|---|---|
| 자료 가져오기 | CSV/JSON의 15개 열·필수값·숫자 범위·중복·현장 정보·날짜·누적값을 검사하고 미리보기 후 전체 교체. 오류·취소 시 기존 자료 유지 | 잘못된 자료와 중복 누적 방지 |
| 현황·추이 | 가져온 뒤 기본값은 2026년 9월·전체 현장. 월·지역·유형·현장 필터, 큰 숫자 4개, 선택 월까지 계획·실제 공정률 추이와 월별 기성 막대 표시 | 현재 상황과 변화 방향을 함께 확인 |
| 점검·비교표 | 공정차이가 작은 순으로 점검 현장 표시, 동점은 현장 ID 순. 지역·유형·당월 주요 공종·금액·공정·상태를 비교하고 행을 펼쳐 공사기간·기록된 상황·대응 계획 확인 | 지연이 큰 현장부터 기록 점검 |
| CSV 내보내기 | 선택 월과 같은 지역·유형·현장 범위만 내보내기. 원본 15개 열과 기성률·공정차이·상태·당월기성액 4개 열 포함. 엑셀의 한글 표시와 숫자·단위 유지 | 엑셀에서 추가 비교·계산 |
| AI에게 묻기 | Gemini가 프로그램의 계산 결과와 원문 기록을 구분해 받아 설명. 답변에 기준 월·현장·근거 숫자·참고 기록 필드 표시. 추이 질문에는 같은 필터의 선택 월까지 월별 요약 활용 | 설명의 근거를 사용자가 확인 |

### 숫자와 범위의 공통 기준

| 항목 | 요구사항 | 이유 |
|---|---|---|
| 화면 기본값 | 처음 열면 자료 없음. 정상 자료를 가져온 뒤 2026년 9월·전체 현장 조회 | 자료를 가져오기 전의 상태와 조회 기본값을 구별 |
| 같은 필터 | 현황·차트·비교표·CSV·AI에 같은 지역·유형·현장 적용. 현재 지표는 선택 월, 추이는 시작 월~선택 월 | 서로 다른 범위의 결과를 비교하지 않도록 함 |
| 현장 선택 초기화 | 지역·유형 변경으로 선택 현장이 범위에서 빠지면 현장 선택을 전체로 변경 | 새 범위에 맞는 결과 표시 |
| 금액·비율 | 금액은 백만원, 비율은 %, 공정차이는 pp(두 비율의 차이). 마지막 표시 단계에서 소수 첫째 자리까지 반올림 | 단위 혼동과 중간 반올림 오차 방지 |
| 기성률 | 현장 또는 선택 월·범위의 누적기성액 합계 ÷ 계약금액 합계 × 100 | 계약금액에 대한 금액 기준 실적 표시 |
| 전체 공정률 | 같은 범위의 계약금액 비중으로 계획·실제 공정률 계산 | 현장 규모를 반영 |
| 공정차이·상태 | 실제 − 계획. 0pp 이상 정상, −5pp 초과~0pp 미만 주의, −5pp 이하 점검. 반올림 전 값으로 계산·판정 | 경계값을 일관되게 구분 |
| 당월기성액 | 같은 현장의 당월 누적기성액 − 바로 전월 누적기성액. 전체 값은 선택 현장 모두의 전월 값이 있을 때만 합산 | 누적액을 당월 실적으로 오해하지 않도록 함 |
| 계산 불가와 0 | 첫 달·전월 없음·자료 없음·분모 없음은 계산 불가. J의 7월 당월기성액 0.0은 정상값 | 누락과 실제 0을 구별 |
| 중복 합산 방지 | 월별 계약금액·누적기성액을 여러 달 합쳐 총액으로 표시하지 않음 | 같은 계약과 누적 실적의 중복 계산 방지 |
| 기록과 상태 | 특이사항 분류는 원문 기록으로 표시하고, 정상·주의·점검은 공정차이로 계산 | “만회 진행”을 정상 판정으로 오해하지 않도록 함 |

### 자료 검사와 AI 설명의 경계

| 항목 | 요구사항 | 이유 |
|---|---|---|
| 자료 교체 | 정상 CSV 다음 같은 JSON을 가져와도 144행. 추가 누적 금지 | 같은 자료의 중복 방지 |
| 일부 자료 | 모든 CSV를 무조건 144행으로 제한하지 않음. 월별 누락은 경고하고 확인 가능한 행만 집계했음을 표시 | 선택 범위 CSV와 정상 원본을 구별 |
| 오류 안내 | 어느 행의 어떤 값이 문제인지, 현재 자료가 유지된다는 안내 표시. 빈값을 0으로 바꾸지 않음 | 사용자가 오류를 이해하고 기존 자료를 계속 이용 |
| AI 계산 역할 | 계산은 프로그램이 수행하고 AI는 전달된 숫자와 기록을 설명 | 계산의 일관성과 검증 가능성 확보 |
| 원문 기록 | 상황은 기록된 상황, 대응은 계획된 대응으로 설명. 원인 확정·실행 완료·효과 보장으로 바꾸지 않음 | 기록에 없는 사실 생성 방지 |
| 과거 기록 | 과거 월의 이유는 해당 월 원문 기록이 전달된 경우에만 설명 | 월별 요약 숫자만으로 원인을 만들지 않도록 함 |
| 자료 밖 질문 | 실제 준공일·미수금 등은 알 수 없다고 안내. 계약상 준공일과 실제 완료일을 구별 | 없는 사실이나 예측을 제공하지 않도록 함 |
| 필터 변경 | 이전 답변 제거. 변경 전 요청의 늦은 답변도 새 범위에 표시하지 않음 | 다른 범위의 설명이 섞이지 않도록 함 |
| AI 실패 | 연결 실패를 안내하고 대시보드·CSV는 계속 사용 가능 | AI 오류로 기본 업무가 중단되지 않도록 함 |

| 로그인·데이터베이스·회사 시스템 연동 | 교육용 파일 분석 범위를 유지 |

| 조건에 없는 추가 기능의 임의 구현 | 확정된 필수 기능과 수업 범위를 유지 |

## 화면 요약

1. 페이지 4개: 현황 요약 / 현장별 비교표 / 자료 가져오기 / AI에게 묻기.
2. 상태 5개: 자료 없음 / 가져오기 오류 / 점검 대상 없음 / AI 답변 대기 / AI 연결 실패.
3. 처음 열면 자료 없음. 가져온 뒤 기본 조회는 2026년 9월·전체 현장.
4. 첫 화면: 필터 → 큰 숫자 한 줄 → 점검 순위 → 계획·실제 추이와 월별 기성.
5. 큰 숫자 예시: 기성률 67.2% / 계획 73.2% / 실제 71.2% / 차이 −2.0pp.
6. 점검 행: 현장명·공정차이·계획/실제 공정률·기성률. 예시 D: −10.7pp·86.5%·75.8%·69.4%.
7. 점검 행을 누르면 같은 필터의 비교표로 이동해 해당 행을 강조하고 공사기간·상황·대응 계획을 펼침.
8. 금액은 백만원, 비율은 %, 차이는 pp. 상태는 정상 ≥0 / 주의 −5 초과~0 미만 / 점검 ≤−5이며 글자로 표시.
9. AI 예시 질문 **(AI 결정)**: “D 현장은 왜 점검 대상이고, 기록된 대응 계획은 무엇인가요?” — 선택한 주 용도 반영.
10. 비교표 행 강조 방식 **(AI 결정)**: 배경 강조와 현장 ID·이름을 함께 표시. 색·분위기는 Stitch 시안을 따름.
